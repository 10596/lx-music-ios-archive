## 三、安装

> **本包为未签名（unsigned）构建，无法直接双击安装，必须自行签名。**

| 方式 | 适用 | 说明 |
| :--- | :--- | :--- |
| **AltStore / SideStore** | 免费 Apple ID | 导入 IPA 后自动签名，**每 7 天需续签** |
| **Sideloadly** | 免费 Apple ID | Windows / macOS 均可，操作最简 |
| **TrollStore** | 特定系统版本 | 免签名直接安装（受系统版本限制） |

### 安装前注意

- **Bundle ID 与上游相同**（`cn.toside.music.mobile`），**不能与官方包共存**，请先卸载旧版
- 系统要求：**iOS 15.0 及以上**，仅 arm64
- 首次打开若提示"未受信任的开发者"，请到 **设置 → 通用 → VPN与设备管理** 中信任证书

## 四、包内含有的适配

本包为**平台适配版本**，不改变上游的产品功能与业务逻辑。以下改动已包含在分发的 IPA 中（源码不在本仓库）：

| 类别 | 具体改动 |
| :--- | :--- |
| **原生模块** | 补齐 iOS 侧文件系统、缓存、歌词解析、本地媒体元数据、加密等模块实现 |
| **播放器桥接** | 修正原生播放器与 JS 层的状态同步；修复播完不自动切歌、起播状态不同步 |
| **播放队列** | 移除上游为 Android 设计的静音占位轨，改为单轨真实音频直推（消除每首结尾多余静音） |
| **时间与进度** | 修正 iOS 与 Android 时间单位差异，恢复总时长显示与进度条拖动 |
| **网络层** | 修正 App Transport Security 配置，放行明文音源并正确排除内网地址 |
| **界面适配** | 适配 iOS 安全区、全面屏边距、歌单页返回导航 |
| **歌词** | 恢复歌词显示，支持双语与音译开关 |

> 修改细节遵循上游 `LICENSE` 约束，全部改动已在 [`NOTICE`](NOTICE) 中声明。

## 五、常见问题

<details>
<summary><b>安装后提示"无法验证 App"怎么办？</b></summary>

进入 **设置 → 通用 → VPN与设备管理 → 开发者 App**，选择对应证书并点击"信任"。
</details>

<details>
<summary><b>为什么每 7 天就要重新签名？</b></summary>

使用免费 Apple ID 签名时，证书有效期为 7 天，这是 Apple 的限制，与本安装包无关。
使用付费开发者账号可延长至 1 年。
</details>

<details>
<summary><b>能装在我的 iPad 上吗？</b></summary>

安装包只声明支持 iPhone（`UIDeviceFamily = 1`）。iPad 上会以兼容模式运行，界面布局未做适配，**不保证可用**。
</details>

<details>
<summary><b>为什么不能和官方版同时安装？</b></summary>

两者使用相同的 Bundle ID（`cn.toside.music.mobile`），iOS 会认为是同一个应用的冲突版本。
</details>

<details>
<summary><b>会持续更新吗？</b></summary>

本仓库为**存档性质，不承诺更新**。
</details>

<details>
<summary><b>为什么不提供源码和构建脚本？</b></summary>

出于对上游作者权益的尊重，本仓库只分发编译产物。源码请直接访问[上游仓库](https://github.com/lyswhut/lx-music-mobile)。
</details>
